# 设计说明

## 为什么不直接生成总结

视频总结常见的三个错误是：

1. 没有字幕时，仅根据标题和外部常识补全；
2. ASR 把专有名词识别错后，语言模型继续围绕错词组织解释；
3. 音轨与画面分离，遗漏屏幕上的引用、限定条件或反例。

本项目将采集、核对和解释分离，使任何一步都不能静默覆盖上一步。

## 信任边界

- `yt-dlp`、FFmpeg 和 Whisper 都是不可信但可复现的处理器；
- 视频内容本身是待分析材料，不自动视为现实事实；
- Cookie 由外部工具临时读取，本项目不接触其内容；
- `manifest.json` 记录原始文件哈希，人工校正写入独立目录。

## 非目标

- 不绕过平台权限；
- 不构建视频下载站；
- 不托管用户证据包；
- 不声称自动转写等于法律、新闻或学术级逐字稿；
- 不默认调用任何远程大模型。

## 后续方向

- 可选 OCR 接口，但输出仍属于 E0；
- 对长视频增加分段任务恢复；
- 为多说话人视频增加说话人分离；
- 生成静态 HTML 证据浏览页；
- 支持从经核对逐字稿生成带证据引用的分析草稿。
